# ✈️ Airline Data Analysis (ETL Pipeline)

This project demonstrates an ETL (Extract, Transform, Load) pipeline for airline flight data using Python, Pandas, and SQL.  
The goal is to clean raw flight data, transform it into an analysis-ready format, and run SQL queries to extract meaningful insights.

---

## Project Overview

The pipeline performs the following steps:

1. **Extract**
   - Reads raw airline flight data from a CSV file.

2. **Transform**
   - Handles missing values
   - Creates new features such as route and stop type
   - Cleans and prepares data for analysis

3. **Load**
   - Loads the transformed data into a database for querying

4. **Analyze**
   - Uses SQL queries to analyze flight patterns and trends
